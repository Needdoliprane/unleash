# Règles Rust et de preuve (pointeur)

Les règles canoniques sont dans le dossier de conception ; lis le fichier qui correspond à ta tâche et applique-le entièrement :

- code Rust, Cargo, dépendances : `.claude/rules/rust.md` ;
- tests et preuves : `.claude/rules/testing.md` ;
- modification du dossier `.claude/` : `.claude/rules/design-dossier.md` ;
- worktrees : `.claude/rules/worktrees.md` (uniquement sous `.claude/worktrees/`).
